1 · Запуск Источник, границы прогона и токен-бюджет

JSON — полный технический лог. Таблица CSV — строки по кейсам с пустыми колонками для ручной оценки в Excel/Google Sheets.

Важно: исторический ответ оператора — только эталон для сравнения. Если для ответа нужны Billing/сеть/PON, replay не выдумывает старые CRM-данные: нормальным решением может быть tool_required.
