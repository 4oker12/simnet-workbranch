# Отдельные Userside-модули

`userside-task-staff-ui.user.js` — самостоятельный модуль назначения исполнителей
заявки, версия `5.9.9-validation-layout-fix`.

Он не входит в `extension/manifest.json`. Такая изоляция намеренная: текущий
Workbench уже проверен как Chrome Extension, а подключение ещё одного большого
DOM-модуля способно изменить поведение UserSide. Перенос этого файла в расширение
нужно выполнять отдельной веткой вместе с DOM-регрессией и live smoke-test.

Файл содержит внутреннюю адресную и бригадную статистику. Не публиковать его в
открытом репозитории без предварительной очистки данных.
