# SIMNET Workbranch

Единый приватный репозиторий инструментов операторской работы SIMNET / LOOKNET.

## Что здесь находится

- `extension/` — основное Chrome Extension **SIMNET / LOOKNET Diagnostic Workbench**;
- `extension/src/workbench.js` — проверенная бизнес-логика Workbench `2.0.0-dev.5.8`;
- `extension/src/training-*.js` — режим обучения и структурированная база подсказок;
- `userscripts/userside-task-staff-ui.user.js` — отдельный Userside-модуль назначения исполнителей `5.9.9-validation-layout-fix`;
- `tests/` — автоматические регрессионные и статические тесты;
- `scripts/` — воспроизводимая сборка ZIP;
- `docs/WORKFLOW.md` — правила совместной разработки через Git.

Userside-модуль `5.9.9` хранится рядом с расширением, но **не подключён** в
`extension/manifest.json` и не меняет поведение Workbench. Его перенос из userscript
в Chrome Extension следует делать отдельной задачей с отдельной проверкой.

## Быстрый старт

Требуется Node.js 20 или новее.

```powershell
npm.cmd test
npm.cmd run package:extension
```

Готовый архив создаётся в `dist/`. ZIP не коммитится: он всегда собирается из
конкретного состояния исходников.

Для локальной установки без ZIP:

1. Открыть `chrome://extensions`.
2. Включить режим разработчика.
3. Нажать **Загрузить распакованное расширение**.
4. Выбрать каталог `extension/`.

Подробности установки и live-проверки: [extension/README.md](extension/README.md).

## Источник истины

После первого push источником истины является ветка `main` этого репозитория.
Файлы из Temp, Downloads, ZIP и установленные копии расширения считаются только
входными материалами или сборочными артефактами. Изменения всегда начинаются с
актуального `main`, проходят тесты и только после этого попадают в релизный ZIP.

## Внутренние данные

Репозиторий должен оставаться приватным. Userside-модуль содержит внутренние
адресные и бригадные статистические данные. Перед публикацией любой части проекта
в открытом доступе эти данные необходимо отдельно удалить или обезличить.
